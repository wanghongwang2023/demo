# 个人主页模板 · 一页式

单文件、零依赖的响应式个人主页。改文字和配色就能用，不需要安装任何环境。

## 一、改内容

用记事本或 VS Code 打开 `index.html`，按下面几处替换成你自己的信息。

| 位置 | 现在写的是 | 改成 |
| --- | --- | --- |
| `<title>` | 林小满 · 产品设计师 | 你的名字 · 你的职业 |
| `.brand` | 林小满 | 你的名字 |
| `.eyebrow` | 产品设计师 · 上海 | 职业 · 城市 |
| `<h1>` | 把复杂的事做得简单一点 | 你的一句话主张 |
| `.lede` | 六年 B 端产品设计经验…… | 两三句自我介绍 |
| 三张作品卡片 | 经营看板重构 / 审批流简化 / 组件库落地 | 换成你自己的项目 |
| 关于我 | 做过四年咨询、两年产品…… | 你的经历 |
| `.skills` 里六个标签 | 交互设计、Figma…… | 你的技能 |
| 邮箱 | hello@example.com | 你的邮箱 |

## 二、改配色

`<style>` 最顶部 `:root` 里改这四个值就够了，整站会跟着变：

- `--paper` 背景色，默认 `#faf8f5` 米白
- `--ink` 文字色，默认 `#1c1a17` 墨黑
- `--accent` 强调色，默认 `#b4471e` 赭红
- `--line` 分割线，默认 `#e3ded6`

想换深色风格：`--paper` 改成 `#16150f`，`--ink` 改成 `#f2efe8`，`--card` 改成 `#1e1d17`。

## 三、发布上线

1. 把 `index.html` 推到仓库
2. 仓库页 Settings → Pages
3. Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存
4. 等 1 分钟左右，访问 `https://用户名.github.io/仓库名/`

## 四、这份模板的特点

- 只有一个文件，双击就能在本地打开，也能直接发给别人
- 不依赖任何外部字体、图片、CDN，断网也能正常显示
- 手机上自动变成单栏
- 改四个颜色值就能整体换风格
